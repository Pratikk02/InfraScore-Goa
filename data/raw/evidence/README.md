# Post-2011 evidence search log

`post2011_search_log.csv` lists every town-facility pair searched for post-2011 evidence: the six towns of the greedy
ten-step plan (for the facilities the plan assigns or that the town lacked) and the thirteen randomly drawn control towns
(for the hospital / fire-station types each lacked in 2011; Ponda lacked neither and was not searched).

Protocol: the same queries for every town; the first page of results was screened for news or government sources
dated after 2011. Coding: **exact** = the source concerns the same facility type (a demand, proposal, sanction or
construction); **related** = a lesser facility of the same kind (e.g. a dispensary or PHC for a hospital); **none** =
nothing relevant found. The coder knew which towns were in the plan, so the coding is not blind; the cited sources
are listed in `outputs/post2011_evidence.csv` and `outputs/post2011_controls.csv` so that others can re-code them.
